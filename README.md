# IA KO NEWS – website tuyên truyền

Website tĩnh dành cho GitHub Pages, gồm 40 bài mẫu:
- 10 bài PCCC (mỗi tháng từ 01/2026 đến 10/2026 có ít nhất 01 bài)
- 10 bài Pháp luật
- 8 bài Cảnh báo ANTT
- 6 bài Chuyển đổi số
- 6 bản tin thế giới

## Đưa lên GitHub Pages
1. Tạo repository mới, ví dụ `ia-ko-news` (public nếu dùng GitHub Free).
2. Tải toàn bộ file/thư mục trong gói này lên **thư mục gốc** repository.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, thư mục `/(root)`, bấm **Save**.
6. Website sẽ có dạng: `https://TEN-TAI-KHOAN.github.io/ia-ko-news/`.

## Cập nhật bài
- Mở `admin.html` trên website.
- Thêm/sửa/xóa bài.
- Bấm **Xuất articles.json**.
- Trên GitHub, thay file `data/articles.json` bằng file vừa xuất và Commit changes.

## Lưu ý
- Không đăng dữ liệu nghiệp vụ, dữ liệu cá nhân, tài liệu mật hoặc nội dung hạn chế phổ biến.
- Các bài mẫu là nội dung biên tập/tóm lược; cuối mỗi bài có liên kết nguồn tham khảo.
- Tin thế giới là tin thời điểm tháng 10/2026, cần cập nhật khi sử dụng lâu dài.

- 24 bài PCCC
- 24 bài An ninh - Cảnh báo
- 21 bài Chuyển đổi số

## Điểm mới V5
- Trang chủ có: Mới cập nhật, Tin nổi bật, Đáng chú ý và 05 khối chuyên mục riêng.
- Khi chọn chuyên mục hoặc tìm kiếm, website chuyển sang giao diện danh sách bài.
- Văn phong 121 bài đã được biên tập lại theo hướng tự nhiên, hạn chế câu mẫu và cách diễn đạt kiểu AI.
- Các bài phối hợp với Công an xã Ia Ko được ghi rõ là nội dung phối hợp; website vẫn mang nhận diện độc lập Gia Lai Số News.
- 08 ảnh thực tế người dùng cung cấp chỉ sử dụng 01 lần/ảnh.
- PCCC có bài đều từ 11/2025 đến 10/2026, bảo đảm mỗi tháng ít nhất 01 bài.
- Trang `admin.html` có ô tìm bài, quản lý đơn vị phối hợp, nhiều nguồn tham khảo và theo dõi tháng PCCC.

## Cập nhật website trên GitHub Pages
1. Upload đè toàn bộ nội dung bản V5 lên repository hiện tại.
2. Chọn **Commit changes**.
3. GitHub Pages sẽ tự cập nhật mà không cần cấu hình Pages lại.

## Tự sửa bài
Mở `admin.html` trên website:
1. Tìm bài bằng ô tìm kiếm.
2. Chỉnh tiêu đề, ngày đăng, chuyên mục, nội dung, ảnh, nguồn hoặc đơn vị phối hợp.
3. Bấm **Lưu vào bản nháp**.
4. Bấm **Xuất articles.json**.
5. Upload file vừa xuất để thay file `data/articles.json` trên GitHub rồi Commit.

Xem trang  
Các thay đổi được lưu trên trình duyệt này. Muốn đưa lên web: bấm “Xuất file cập nhật website”, rồi upload file seed-posts.js lên GitHub.

Bài viết mới

Ảnh chọn từ máy sẽ tự thu nhỏ để tránh file dữ liệu quá nặng. Khi xuất bản, ảnh được nhúng trực tiếp vào seed-posts.js.
Có thể chọn nhiều ảnh. Mỗi ảnh có nút Xóa riêng trong phần xem trước.
